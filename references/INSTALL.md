# 干净安装与高级命令

当前包版本为 `2.2.0`；版本号本身不证明已安装、已验收或已发布。工作版本、验收基线、Git 发布版本和安装副本分别核实。

需要 Python 3.9+、Git 和可信的本地源码。以下工具只使用标准库，无网络下载。助手先确认你授权安装的准确来源提交，再执行。不要把仓库根目录、GitHub 自动生成的整个源码压缩包或私人备份直接复制进 Skill 发现目录。

```sh
python3 <SKILL_DIR>/scripts/package_skill.py build --repo <SOURCE_CHECKOUT> --source <FULL_SOURCE_COMMIT> --output <CLEAN_ARCHIVE_PATH>
python3 <SKILL_DIR>/scripts/install_skill.py --repo <SOURCE_CHECKOUT> --source <FULL_SOURCE_COMMIT> --archive <CLEAN_ARCHIVE_PATH> --destination <NEW_INSTALLATION_DIRECTORY>
```

安装目录的父目录应已存在；目标目录必须完全不存在，包括空目录和符号链接。工具先把压缩包固定为一份字节快照，核对来源提交、清单、文件哈希、精确成员列表及路径，再创建新目录。失败会清理本次创建的目录。它拒绝覆盖已有安装，不自动迁移或删除备份。升级时先由用户明确安排已有安装的保存位置，再使用全新的目标；备份须放在 Skill 发现目录以外。

安装是本地文件操作，不代表验收或发布。验证和写入使用相同压缩包快照，但不防范同一账户的恶意进程在安装期间篡改文件。只在受信任、没有其他写者的父目录执行。源码和安装器都应来自可信渠道，清单不是签名。当前安装器只支持自身明确的运行文件列表；旧版或将来新增文件的包须使用对应可信版本的安装器，不从压缩包运行代码。

运行包包含五个模板、协议及格式/协调/安装参考、检查/打包/安装/协调脚本和必要元数据；不包含当前项目状态、历史任务、审计报告或私人运行记录。压缩包由不可变源码提交生成且可重复。精确文件清单与哈希是结构边界；路径、运行编号和私钥文本扫描是额外防护，不是所有秘密的识别保证。

需要进一步操作时，请参阅 [工作记录格式](WORK_FORMAT.md)、[本地协调命令](COORDINATION.md) 和 [完成检查](GATE.md)。
